# Security Policy

## Supported Versions

Clerkenwell has not reached 1.0. Only the latest commit on `main` covers fixes;
update to it to pick one up.

## Reporting a Vulnerability

Report privately through GitHub's advisory form for this repository:
https://github.com/thirtytwobits/clerkenwell/security/advisories/new

Do not open a public issue for a security report.

Include the affected crate or npm package, the commit or version, and steps to
reproduce. A confirmed vulnerability is fixed and disclosed through a GitHub
Security Advisory.
